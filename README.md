## How it works

`draw.py` (Pillow) renders `entry.png` (1024×1024, < 1 MiB). `main.py`
(stdlib only) copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`.

```sh
python3 draw.py
MAKEFUN_OUTPUT_DIR=out python3 -P -s main.py
```
